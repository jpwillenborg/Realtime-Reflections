# Realtime-Reflections
Realtime planar reflections in Unity
<br><br>

![Project Image](<./.gitimages/Realtime Reflections 01.png>)
<br><br>

## Project Description
This example focuses on applying a reflective planar surface in Unity without a URP renderer feature or reflection probes. The scene allows you to adjust the reflectiveness of the floor's top surface as well as the brightness of the material's base map. In addition, the reflective surface receives real-time shadows (in this example from the player). Baked lightmaps were added in conjunction with an Adaptive Probe Volume to render more logical shadows from the mixed lighting in Shadowmask mode.
<br>

Note: Some assets from the Unity Asset Store are required for a complete build. They are not included in this repo. Please see the Licenses section below for links to the assets. Otherwise, feel free to browse through the project files. Thanks.
<br><br>

## Player Controls
Move Player: WASD Keys -or- Arrows
<br>
Jump: Spacebar
<br><br>

## Project Features
* Reflective planar surface
* Adjustable level of reflection and brightness
* No URP renderer feature or reflection probes added
* Traditional baked lightmaps
* Adaptive Probe Volume for shadows
* Framerate counter
